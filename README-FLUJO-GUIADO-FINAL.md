# Flujo guiado + modo rápido

## Home Figus
Se separan dos entradas claras:

### Camino guiado
1. Cargar álbum y repetidas.
2. Revisar checkpoint: tenés / faltan / repetidas.
3. Ver usuarios cercanos en lista.

### Modo rápido
Entra directo a `/figus/descubrir`, formato Tinder/swipe por distancia.

## Nueva página
`/figus/guiado`

Muestra todos los usuarios compatibles en lista con:
- Nombre
- Distancia
- Porcentaje de álbum completo
- Cantidad de figus que recibís
- Cantidad de figus que entregás
- Intercambio 1x1 / 2x2 / ayuda simple
- Botón contactar

## Filtros/orden
En `/figus/guiado` se puede ordenar por:
- Cercanía
- Mayor cantidad de intercambio posible

## Notas
- El modo guiado requiere ubicación.
- El modo rápido mantiene el swipe y match mutuo.
- Ejecutar `supabase/TODO_SUPABASE_COMPLETO.sql` si no estaba actualizado.
